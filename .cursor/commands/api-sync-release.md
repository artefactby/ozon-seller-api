# Мини-ревью синхронизации API и подготовка релиза

Выполни процедуру «Мини-ревью релиза» из `MAINTAINER.md` — этот раздел является
источником истины. Следуй ему дословно: входные данные, порядок работы, правила
выбора версии, отдельный порядок при breaking changes и ограничения.

Кратко: ты на ветке `api-sync/*` после `npm run api-sync`; сверь обновление,
опиши его в `CHANGELOG.md`, подними `version` в `package.json`, закоммить и
запушь. Публикацию, тег и GitHub Release после merge делает CI — их не трогать.
Данные об обновлении Ozon (в любом формате) — опциональный слой сверки: если их
нет, продолжай и зафиксируй в CHANGELOG, что сверка с анонсом не проводилась.
